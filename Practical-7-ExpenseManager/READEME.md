# Experiment 7: Expense Manager Application

A simple Expense Manager mobile application developed using **React Native and Expo**. The application allows users to add income and expenses, select categories, view the running balance, and delete transactions. It also includes input validation with alerts.

## Technologies Used
- React Native
- Expo
- JavaScript
- React Native Widgets/Components

## Features
- Add Income and Expenses
- Select transaction categories
- View Income, Expense, and Balance
- Delete transactions
- Input validation and alerts
- Responsive UI

## Run the Project

```bash
npx expo start
