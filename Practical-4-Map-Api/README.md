# Map Demo App

A Flutter and Dart application that integrates Google Maps and displays an interactive map with location markers.

## Features

- Interactive Google Map
- Current location detection
- Mumbai and College markers
- Marker information
- Zoom and map controls
- Recenter to current location

## Technologies Used

- Flutter
- Dart
- Google Maps JavaScript API
- `google_maps_flutter`
- `geolocator`
- Google Chrome

## Run the Project

change the API key in web -> index.html file 
```bash
flutter pub get
flutter run -d chrome
