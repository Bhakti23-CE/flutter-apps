# Experiment 6 – React Native Counter App

## Aim
To develop a simple cross-platform application using React Native and Expo.

## Description
This is a simple Counter App developed using React Native.

The app allows the user to:
- Increase the counter value
- Reset the counter to 0

## Concepts Used
- React Native
- View and Text
- Button
- useState
- Event Handling
- StyleSheet
- Flexbox

## Technologies
- React Native
- Expo
- JavaScript

## How to Run

```bash
npm install
npx expo start
