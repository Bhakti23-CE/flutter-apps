# Experiment 3: Developing Adaptive and Responsive Designs in Flutter

## Aim
To implement adaptive and responsive UI techniques in Flutter so that the application adjusts to different **screen sizes and orientations**.

## Concepts Used
- MediaQuery
- LayoutBuilder
- OrientationBuilder
- Expanded
- Flexible
- Wrap
- Responsive Design
- Adaptive Design

## Description
This experiment modifies the existing Flutter application to automatically adjust its layout for **mobile, tablet, and desktop/web** screens. The layout also responds to **portrait and landscape orientations** while maintaining the existing application design.
