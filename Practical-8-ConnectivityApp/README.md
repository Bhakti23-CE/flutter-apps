# Experiment 8: Connectivity-Based Application Using React Native

## Aim
To develop a cross-platform application that detects network connectivity, displays online/offline status, identifies the connection type, and updates automatically when connectivity changes.

## Technologies Used
- React Native (Expo)
- JavaScript
- NetInfo
- Node.js and npm
- Android Emulator

## Features
- Displays online/offline status.
- Identifies Wi-Fi and cellular connections.
- Shows internet reachability.
- Updates automatically when connectivity changes.
- Provides a manual Refresh button.
- Displays the last-updated time.

## Installation and Execution

1. Navigate to the project directory:

   ```bash
   cd ConnectivityApp

2. Add App.js code
3. Install dependencies:
   ```bash
   npm install

4. Start the application:
   ```bash
   npx expo start

6. Start the Android emulator and press a in the terminal.
