# Experiment 10: Develop Xamarin Applications Using Layouts and Views

## Application Name
**FoodieExpress – Food Delivery Dashboard**

## Aim
To develop a cross-platform mobile application demonstrating different layouts and views using .NET MAUI.

## Components Used

**Layouts:**
- ScrollView
- StackLayout
- Grid
- AbsoluteLayout
- FlexLayout

**Views:**
- Label
- Image
- Button
- Entry
- BoxView
- Frame
- ActivityIndicator

## Features
- Customer profile with membership details.
- Orders, favourites and rewards statistics.
- Food category tags with selection functionality.
- Notification icon with a badge.
- Search bar for dishes and restaurants.
- Promotional discount banner.
- Order Now button with confirmation message.
- Scrollable dashboard with wrapping category tags.

## Technologies Used
- C#
- XAML
- .NET MAUI
- Visual Studio 2026
- .NET 10
- Android Emulator (Pixel 7 – API 36)

## How to Run
1. Open the project in Visual Studio.
2. Restore NuGet packages.
3. Start the Android emulator.
4. Select the emulator as the deployment target.
5. Press **F5** to build and run the application.

## Conclusion
Successfully developed and executed a Food Delivery Dashboard using .NET MAUI, demonstrating the use of different layout containers, views, event handling and responsive UI design.

**Note:** .NET MAUI was used as the replacement for Xamarin.Forms because Xamarin.Forms is discontinued.
